# Как участвовать в исследовании №11

1. Перед PR воспроизведите **исходный** опыт, сохраните команду запуска, версию Python/компилятора, ОС и архитектуру CPU/GPU.
2. Изменения алгоритма отделяйте от чистки форматирования. Новые результаты не подменяют старые: сохраняйте сырые JSON/CSV в новой директории с датой и commit SHA.
3. Применяйте одни и те же seed, данные, бюджет и измерительные единицы для сравниваемых методов; описывайте отличия.
4. Дублируйте контроль корректности: checksum, тест эквивалентности, инварианты, проверка отсутствия утечки данных там, где уместно.
5. Не добавляйте секреты, приватные данные, недоступные датасеты или скопированные чужие материалы без разрешённой лицензии.
6. В PR опишите цель, метод, среду, команду воспроизведения, результаты, ограничения и причину существенных отклонений.

Убедитесь, что выводы не сильнее данных; сверяйтесь с [ограничениями](docs/EVIDENCE_SCOPE.md).
