# Безопасность

Исходники предназначены для контролируемых учебных/исследовательских сред. Не запускайте fault-injection, нагрузочные и инфраструктурные сценарии в production без отдельного разрешения. Эксперименты с рыночными данными не являются инвестиционной рекомендацией.

**Секреты:** не коммитьте API-ключи, токены, данные пользователей или конфигурацию доступа. Используйте переменные окружения и минимально необходимые разрешения.

**Уязвимости:** сообщайте приватно владельцу репозитория через GitHub Security Advisories (если функция доступна) или согласованный приватный канал. Не открывайте issue с действующими секретами.

**Границы доверия:** внешние датасеты и зависимости требуют проверки источника; результат CI, запуск тестов и формальное наличие allowlist не доказывают безопасность архитектуры.
